The goal is to have a repository of all the problems and their solutions in Striver's A2Z SDE Sheet. 
Most of the problems were taken from his Sheet and an appropriately named file for each one has been named so. 
A [structure](https://github.com/yazh1202/DSA/blob/master/Structure.md) file is present as to how to create a solution file for any problem. Obsidian is used to create a vault for all the problems, so that they can be tested by just copy pasting into any coding practice site.
